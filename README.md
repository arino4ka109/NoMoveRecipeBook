# No Move Recipe Book

**No Move Recipe Book** is a mod that fixes a common problem for many in Minecraft. It keeps the position of your interface (inventory, crafting table, furnace, etc.) when opening the Recipe Book.

### 📌 What does this mod do?

In the vanilla game, opening the recipe book shifts the main window (inventory, crafting table, furnace) to the side.

This mod prevents the main GUI from shifting. The crafting menu or inventory stays in its place, and the recipe book opens on the side.
